# CLASSES:

Classes are the basic units of object-oriented programming. A class is a blueprint from which individual objects are created. It defines the properties and behavior of the objects that are created from it. Classes contain the data and the code that operates on that data. Classes are used to create objects which are instances of the class.

A class consists of the following parts:

1. **Class name**: The name of the class.
2. **Fields**: These are the variables that are declared inside the class. They can be of any type, e.g. primitive, reference, etc.
3. **Constructors**: These are special methods that are used to initialize the objects of the class.
4. **Methods**: These are the functions that are declared inside the class. They can be of any type, e.g. static, non-static, etc.

# OBJECTS:

Objects are the instances of the classes. They are the real entities that have their own set of attributes and behaviors. Objects can be created using the `new` keyword.

An object has three main characteristics:

1. **State**: The set of attributes of an object.
2. **Behavior**: The set of methods of an object.
3. **Identity**: The set of unique characteristics of an object.

# CONSTRUCTORS:

Constructors are special methods that are used to initialize the objects of the class. A constructor has the same name as the class and has no return type. Constructors can be overloaded to have different parameters.

Constructors are used to:

1. Initialize the objects of the class.
2. Set the values of the fields of the class.
3. Perform any other initialization tasks.

# STATIC KEYWORD:

The `static` keyword is used to denote that a field or method is associated with the class itself, rather than with any object of the class. Static fields and methods are accessible without creating an object of the class.

# THIS KEYWORD:

The `this` keyword is used to access the current object of the class. It is used to refer to the current object of the class.

# INHERITANCE:

Inheritance is the process of creating a new class from an existing class. The new class inherits the properties and behavior of the parent class. A class can inherit from multiple parent classes.

# ASSOCIATION:

Association is the process of creating a relationship between two classes. Association is used to represent the relationship between two classes.

# POLYMORPHISM:

Polymorphism is the ability of an object to take on multiple forms. It is used to represent the same object in different forms.

# METHOD OVERLOADING:

Method overloading is the process of declaring multiple methods with the same name but with different parameters. It is used to provide different implementations of a method.

# METHOD OVERRIDING:

Method overriding is the process of declaring a method in a subclass with the same signature as a method in the parent class. It is used to provide a different implementation of a method.

# COVARIANT RETURN TYPE:

Covariant return type is a feature of Java that allows a method to return a subtype of the type declared in the method signature. It is used to return a subtype of the type declared in the method signature.

# SUPER KEYWORD:

The `super` keyword is used to access the parent class of the current class. It is used to refer to the parent class of the current class.

# FINAL KEYWORD:

The `final` keyword is used to declare that a class, method or field is final. It is used to prevent a class from being subclassed, a method from being overridden and a field from being reassigned.

# STATIC & DYNAMIC BINDING:

Binding is the process of linking a method call with the code that implements the method. It can be either static or dynamic. Static binding is done at compile time while dynamic binding is done at runtime.

# ABSTRACT CLASSES:

Abstract classes are the classes that contain one or more abstract methods. Abstract classes cannot be instantiated and must be subclassed. Abstract classes are used to provide a basic implementation of a class.

# INTERFACES:

Interfaces are the abstract classes that contain only abstract methods. Interfaces are used to define a contract that must be implemented by any class that implements it.

# ACCESS MODIFIERS:

Access modifiers are the keywords that are used to control the access to a class, field or method. They are used to define the visibility of a class, field or method.

# NON-ACCESS MODIFIERS:

Non-access modifiers are the keywords that are used to define the behavior of a class, field or method. They are used to provide additional information about the class, field or method.

# ENCAPSULATION:

Encapsulation is the process of hiding the internal implementation details of an object from the outside world. It is used to protect the internal state of an object from external interference.

# WRAPPER CLASSES:

Wrapper classes are the classes that are used to wrap primitive data types in an object. They are used to create objects from primitive data types.
